# Gen-AI-Powered-Clothing-Store-with-Pydantic-AI
Develop a Gen AI-powered clothing store that leverages Pydantic AI for intelligent product retrieval and customer interaction. This project involves building an AI agent for personalized shopping experiences . The application features a chatbot interface, product catalog management, and order processing, deployed using CI/CD on AWS.
